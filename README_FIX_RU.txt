My Money v2.8.0 — исправленная сборка исходников

Что исправлено:
1. Удалён дублированный фрагмент js/script.js. В исходном архиве JavaScript содержал два экземпляра приложения и завершался SyntaxError: Identifier 'firebaseConfig' has already been declared. Из-за этой ошибки браузер не выполнял скрипт приложения целиком.
2. Экран приветствия показывает время и дату в часовом поясе Asia/Almaty. Время обновляется каждую секунду, формат 24 часа.
3. Погода для координат Алматы загружается из Open-Meteo через HTTPS, без кеширования браузером; повторное обновление каждые 10 минут, при возвращении приложения на экран и при восстановлении сети. При ошибке выводится понятный статус.
4. Переписан Slide to Unlock на Pointer Events с pointer capture, обработкой pointermove/up/cancel, адаптацией к изменению размера окна и клавиатурной разблокировкой Enter/Space.
5. Добавлены CSS-правила touch-action/user-select для корректного свайпа на Android WebView и мобильных браузерах.
6. Полностью удалено обновление свайпом сверху вниз (pull-to-refresh) — на телефоне и на ПК, в браузере и в обёртке WebIntoApp.
   Обёртка WebIntoApp (Android SwipeRefreshLayout) запускает обновление только когда WebView прокручен в самый верх.
   Теперь весь интерфейс закреплён на экране (position: fixed), а сам документ скрипт постоянно держит прокрученным
   на 200px (disablePullToRefresh в js/script.js, блок «PULL-TO-REFRESH ПОЛНОСТЬЮ ОТКЛЮЧЁН» в css/style.css).
   Для обёртки страница никогда не бывает «вверху», поэтому жест не срабатывает даже при включённой опции в WebIntoApp.
   Пользователь корневой документ прокрутить не может (overflow: hidden), прокручиваются только внутренние области.
   В браузерах дополнительно стоит overscroll-behavior: none/contain. Удалена старая нерабочая заглушка touchmove.

Проверки:
- node --check js/script.js — успешно.
- HTMLParser для index.html — успешно.
- ZIP проверен на целостность.

- В архиве находятся исходные файлы (index.html, css/style.css, js/script.js), а не подписанный APK.
- На ПК заставка по-прежнему пропускается автоматически согласно существующей логике приложения; слайдер предназначен для мобильного экрана.
