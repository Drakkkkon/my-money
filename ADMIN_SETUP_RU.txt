My Money 4.1 — журнал действий и администратор (подключается один раз, ~10 минут)

Администратор — аккаунт Lego2009as@gmail.com. Только ему видны каталог OldBook.kz (блок на «Стене») и блок «Администратор: пользователи» в Настройках.
У сайта нет своего сервера, поэтому список пользователей хранится в ВАШЕЙ Google Таблице, а принимает данные бесплатный скрипт Google.
Пока шаги ниже не сделаны, всё остальное работает; блок администратора просто пишет «журнал не подключён».

ШАГ 1. Таблица и скрипт (под аккаунтом Lego2009as@gmail.com)
1. sheets.new — пустая Google Таблица, назовите «My Money — журнал».
2. Расширения → Apps Script. Удалите весь текст в Code.gs и вставьте содержимое файла admin_server/Code.gs из архива.
3. В строке CLIENT_ID замените заглушку на ваш Client ID — тот же, что в js/config.js (googleClientId). Сохраните (дискета).

ШАГ 2. Публикация
1. Развернуть → Новое развертывание → тип «Веб-приложение».
2. «Запуск от имени»: Я. «У кого есть доступ»: Все. (Нужно, чтобы сайт мог отправлять события. Защита другая: скрипт принимает только настоящий
   токен Google вашего приложения, почту берёт из токена, а список пользователей отдаёт только Lego2009as@gmail.com.)
3. Развернуть, разрешить доступ (Google предупредит «приложение не проверено» — Дополнительно → Перейти: это ваш скрипт).
4. Скопируйте «URL веб-приложения»: https://script.google.com/macros/s/.../exec

ШАГ 3. Адрес — в js/config.js на GitHub (ваш файл с ключами; в архивы обновлений он не входит)
Добавьте строку (после googleAppId запятая): adminLogUrl: 'https://script.google.com/macros/s/ВАШ_АДРЕС/exec'
Образец — js/config.example.js.

ШАГ 4. Проверка
1. Откройте сайт под Lego2009as@gmail.com: на «Стене» есть каталог OldBook.kz, в Настройках — «Администратор: пользователи». Появится окно «Журнал действий» — «Согласен».
2. Откройте пару разделов, подождите минуту. Настройки → Администратор → «Обновить»: вы в списке; нажмите на строку — действия.
3. Под другим аккаунтом: каталога на «Стене» нет, блока администратора нет; окно согласия появляется у каждого пользователя.

В журнал попадает (то же сказано в окне согласия): почта и имя из Google, открытые разделы, то, что вписано в строки поиска и ввода (каталог книг, цены,
котировки, ссылка на товар, название цели, список покупок), способ и итог распознавания фото, тип и категория новой записи.
Не передаётся: суммы, комментарии, баланс, названия подписок, пароли, ключи распознавания.
Пользователь отключает журнал в Настройках → «Журнал действий» — его строки в таблице стираются.

Другой администратор: поменяйте почту в двух местах — admin_server/Code.gs (ADMIN_EMAIL) и js/admin.js (ADMIN_EMAILS).
