MY MONEY КАК САЙТ: GITHUB PAGES + ВХОД ЧЕРЕЗ GOOGLE + ДАННЫЕ НА GOOGLE ДИСКЕ
=============================================================================

Что получится
-------------
- Сайт https://ВАШ_ЛОГИН.github.io/my-money/ — тот же дизайн и все функции.
- Новая версия появляется у всех сама: достаточно загрузить изменённые файлы на GitHub.
- Данные хранятся на Google Диске (папка «My Money», файл my_money_data.json) и синхронизируются
  между телефоном, планшетом и ПК. Без интернета приложение работает и досылает изменения позже.
- На телефоне сайт ставится как приложение: Chrome → ⋮ → «Установить приложение» / «Добавить на главный экран».
- Excel и PDF скачиваются, имя файла: дата_время_имя (например 2026-11-01_14-30_Айдар.xlsx).

Названия пунктов в GitHub и Google Cloud могут немного отличаться — ищите похожие.


ШАГ 1. Аккаунт GitHub и репозиторий
-----------------------------------
1. Зарегистрируйтесь на https://github.com (бесплатно).
2. Справа вверху «+» → «New repository».
3. Repository name: my-money. Видимость: Public (бесплатный GitHub Pages работает с публичными
   репозиториями; ваши финансовые данные туда НЕ попадают — они только на вашем Google Диске).
4. «Create repository».


ШАГ 2. Загрузить файлы и включить сайт
--------------------------------------
1. В репозитории: «Add file» → «Upload files».
2. Распакуйте архив и перетащите В ОКНО ВСЁ его содержимое: index.html, sw.js, manifest.webmanifest,
   папки css, js, images (index.html должен оказаться в корне репозитория, не внутри папки).
3. Внизу «Commit changes».
4. Settings (вкладка репозитория) → слева «Pages».
   Source: «Deploy from a branch». Branch: main, папка «/ (root)» → «Save».
5. Через 1–3 минуты вверху страницы Pages появится адрес сайта:
   https://ВАШ_ЛОГИН.github.io/my-money/
   Откройте его — приложение работает уже сейчас (данные пока хранятся только на устройстве).


ШАГ 3. Ключ для входа через Google (Client ID) — один раз, ~10 минут
--------------------------------------------------------------------
1. Откройте https://console.cloud.google.com и войдите тем же Google-аккаунтом.
   Вверху выберите проект money99774 (это ваш проект Firebase) или создайте новый проект.
2. «APIs & Services» → «Library» → найдите «Google Drive API» → «Enable».
3. «Google Auth Platform» (или «OAuth consent screen»):
   - Branding / App information: имя приложения «My Money», ваш email поддержки.
   - Audience: тип «External», статус «Testing».
     В «Test users» добавьте свой Gmail (и Gmail тех, кто ещё будет пользоваться, до 100 человек).
   - Data access / Scopes: добавьте .../auth/drive.file, а также openid, email, profile.
4. «Clients» (или «Credentials» → «Create credentials» → «OAuth client ID»):
   - Application type: «Web application», имя любое.
   - Authorized JavaScript origins → «Add URI»:  https://ВАШ_ЛОГИН.github.io
     (только начало адреса, без /my-money/ и без слеша в конце).
   - Redirect URIs не нужны. «Create».
5. Скопируйте «Client ID» (вида 123456789012-abc...xyz.apps.googleusercontent.com).
6. Откройте у себя файл js/config.js в Блокноте и вставьте его вместо ВСТАВЬТЕ_СЮДА_CLIENT_ID...:
       googleClientId: '123456789012-abc...xyz.apps.googleusercontent.com'
   Сохраните файл.
7. На GitHub зайдите в папку js → «Add file» → «Upload files» → загрузите новый config.js → «Commit changes».
   (Client ID — не секрет, его можно хранить в публичном репозитории.)


ШАГ 4. Первый вход
------------------
1. Откройте сайт → Настройки → «Войти через Google».
2. Google покажет «Приложение не проверено Google» — это нормально для личного приложения
   в статусе Testing: «Продолжить». Поставьте галочку доступа к Google Диску.
3. Приложение создаст на Диске папку «My Money» с файлом my_money_data.json и начнёт синхронизацию.
4. Если всплывающее окно не открылось — разрешите всплывающие окна для сайта в браузере.

Google выдаёт вход на 1 час. Если приложение открыто дольше или открыто снова позже,
в Настройках появится кнопка «Продолжить синхронизацию» (или нажмите круглую кнопку синхронизации).
Изменения при этом не теряются: они сохраняются на устройстве и отправятся после подтверждения.


ШАГ 5. Перенос старых данных
----------------------------
Сайт — это новый адрес, поэтому данные из APK/старого браузера сами не появятся. Варианты:
- Настройки → «Перенести данные из старого аккаунта (вход по email)» → email и пароль прежнего облака.
- Или в старом приложении: Настройки → «Локальная копия (JSON)» → «Скопировать таблицу/данные»,
  сохранить в файл .json и на сайте: Настройки → «Загрузить файл».


ШАГ 6. Установка на телефон
---------------------------
Android (Chrome): откройте сайт → ⋮ → «Установить приложение» (или «Добавить на главный экран»).
iPhone (Safari): «Поделиться» → «На экран Домой».
Приложение открывается без адресной строки, работает без интернета, обновляется само.


КАК ВЫПУСКАТЬ ОБНОВЛЕНИЯ
------------------------
Загрузите изменённые файлы в репозиторий на GitHub («Add file» → «Upload files», файлы с теми же
именами заменятся). Через 1–3 минуты сайт обновится; установленное приложение подхватит новую
версию при следующем открытии. Переустанавливать ничего не нужно. js/config.js с вашим Client ID
не затирайте файлом из нового архива (в новом архиве там снова будет «ВСТАВЬТЕ_СЮДА»).


ВАЖНО
-----
- Вход через Google не работает внутри APK от WebIntoApp: Google запрещает вход во встроенных окнах
  приложений. Пользуйтесь сайтом в Chrome или установите его на главный экран (шаг 6).
- Доступ drive.file: приложение видит на вашем Google Диске только свои файлы.
- Удаление «Сбросить всё» при входе в Google удаляет данные и на Диске, и на других устройствах.
